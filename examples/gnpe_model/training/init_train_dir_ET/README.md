# ET initialization model checkpoint

The ET initialization checkpoint `model_latest.pt` is published as an asset in
the [ET initialization model 2026-11-17 release](https://github.com/ChiPENG1003/dingo/releases/tag/et-init-model-2026-11-17).

Download it into this directory. Its size is 727,957,853 bytes and its
SHA-256 checksum is `47bac60beae9a826d941e301c61197c43ebf2c4474532b1b7655be5091afa55d`.

The checkpoint is a Release asset because GitHub rejects regular Git files
larger than 100 MiB and this public fork cannot upload new Git LFS objects.
