# ET best model checkpoint

The single ET best model checkpoint for this branch is published as the
`best_model.pt` asset in the [ET best model 2026-11-17 release](https://github.com/ChiPENG1003/dingo/releases/tag/et-best-model-2026-11-17).

Download it into this directory. Its size is 1,570,508,615 bytes and its
SHA-256 checksum is `71335af35a10d47e00a9e6a48ac2326ab650e19011e45f7bab780cf34f7ae25f`.

The checkpoint is a Release asset because GitHub rejects regular Git files
larger than 100 MiB and this public fork cannot upload new Git LFS objects.
